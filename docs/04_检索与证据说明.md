# 检索与证据说明

日期：2026-10-23。检索为定向滚动检索，不声称穷尽全部研究。未使用付费全文或非公开材料。

## 检索范围与方法

先使用宽泛主题词定位研究线，再沿论文摘要、正式出版页、作者代码链接追踪。优先采用 arXiv、会议官网、出版机构、国家科技期刊平台和作者 GitHub。检索结果中的二手解读仅作发现线索，不作为最终技术结论依据。

代表性查询：

```text
knowledge graph enhanced situation prediction decision making planning world model
knowledge graph situation awareness military decision making prediction
knowledge graph world model planning agent
temporal knowledge graph forecasting RE-GCN TLogic TiRGN
知识图谱 态势预测
知识图谱 指挥决策
知识图谱 战场态势估计
```

收录标准：能解释状态表示、未来预测、规划、领域决策支持或对应评估；有可核验的原始来源。通用世界模型仅选少量基础文献；未把视频生成论文作为本轮重点。工程必须有已访问的官方仓库；未确认的代码地址留空。

## 阅读深度与证据限制

论文卡片逐项标记核验深度。核心工作的正文进行了定向阅读；其余多为摘要、出版信息或仓库核验，不写成“已通读”。未复现任何性能数值；为避免条件不一致，未制作跨论文指标排行榜。

本轮三个重要的核验结果：

1. [AriGraph](https://www.ijcai.org/proceedings/2025/2) 的正式发表年份为 2025，arXiv 首发为 2024。
2. [arXiv:2410.09252](https://arxiv.org/abs/2410.09252v2) 的最新标题为 DAVIS，早期 ReasonPlanner 是同一条版本线索，不算两篇独立工作。
3. [ARES-KG 作者仓库](https://github.com/dimitrisdoumanas19/DSS-ARESKG) 主要提供数据与文档形式的查询材料。论文中声称可得的工件与仓库实际可见文件是否完全一致，后续复现需继续核对。出版页直接抓取曾返回 429，本轮结合出版页搜索可见内容和作者仓库核验。

[TiRGN](https://www.ijcai.org/proceedings/2022/299) 的官方搜索结果可见，但直接抓取失败，全文和代码待复核。KGLAMP、Worldformer、E-KELL 未核实独立作者仓库，不据此断言“不开源”。

## 可复核记录

- `data/arxiv_metadata.json`：6 篇重点论文的标题、作者与许可链接，从 arXiv 摘要页读取。
- `data/repositories.json`：GitHub API 核验的仓库 URL、默认分支、许可识别、提交 SHA、核验日期和未运行状态。
- `data/pdf_manifest.json`：收录 PDF 的固定版本、来源、作者、许可与 SHA-256。
- `data/papers.json`：人工筛选的研究条目。`code` 可能指作者工程、论文列表或项目页，详细用途在卡片和工程索引中区分。

日期为本轮采集时间，不代表永久有效。后续更新需要保留版本变化记录。
