# 知识图谱增强的态势预测与任务规划：方法、证据与研究方向综述

版本：第二轮，2026-10-23。基于本仓库 21 项论文资料及 11 个工程索引，补充核心正文与固定提交下的工程静态审查。本文是围绕课题的叙述性综述，未采用穷尽检索或元分析，不把作者报告的结果表述为本团队已经复现的结果。工程判断另见 [复现可行性报告](06_复现与测试可行性.md)。

## 摘要

“知识图谱增强的态势预测与指挥决策”横跨知识表示、时序事件预测、世界模型和任务规划，现有工作使用的“世界模型”一词并不对应同一种技术对象。有些模型保存和检索环境知识，有些从历史外推未来事件，有些显式预测动作造成的状态变化，还有些把图转换为符号规划问题。若仅按名称归类，容易把问答能力、预测能力和行动收益混为一谈。本文以知识所处位置和被验证能力为两条分类轴，对代表工作进行比较，并分析其数据、评估和工程证据。本文判断：近期可行的研究入口是规范的时序图预测和结构化记忆对照；向完整决策闭环扩展时，应补上行动条件状态转移、约束验证及反馈更新。第一批候选为 TLogic、AriGraph，以及解决环境兼容问题后的 RE-GCN；DAVIS、WKM 和 KGLAMP 更适合先研究其方法或前置条件。本文没有安装依赖、调用实验模型、训练或运行测试。

关键词：知识图谱；态势预测；世界模型；时序推理；任务规划；可复现性

## 1. 问题边界与研究问题

态势信息通常具有多源、局部可观测、随时间变化和关系密集等特征。面对任务目标，系统需要回答三个连续但不同的问题：当前知道什么、未来可能发生什么、采取什么行动可以改善结果。知识图谱可为三者提供结构，然而三者要求的数据和证据不同。

本文将“指挥决策”限定为辅助人类理解态势、比较任务方案与配置资源的研究目标，先以公开的应急调度或文本交互环境讨论验证方式。通用环境可以检验机制，不能直接证明真实指挥系统的有效性。

本综述回答四个问题：

1. 知识图谱在状态、预测与规划中分别承担什么角色？
2. 不同论文实际验证了哪些能力，哪些结论不能相互替代？
3. 当前数据与工程是否支持进一步复现或机制测试？
4. 在资源有限时，怎样收敛为可以被证伪的研究问题？

纳入范围与首轮来源见 [论文卡片](02_论文卡片.md)；本轮逐项工程证据见 [静态审查记录](07_第二轮证据审查.md)。没有取得全文的中文工作仍按摘要级证据处理。

## 2. 一个统一的分析框架

### 2.1 把世界表示、动态模型和规划器分开

为便于比较，本文采用如下分析性表示，而非宣称所有论文均实现这些模块：

\[
G_t=U(G_{t-1},o_t,a_{t-1};K),\qquad
\widehat{G}_{t+1}\sim F_\theta(G_t,a_t;K),
\]

\[
a_{t:t+H-1}^{*}\approx\arg\max_{a_{t:t+H-1}}\mathbb{E}_{F_\theta}
\left[\sum_{h=0}^{H-1}\gamma^hR(\widehat G_{t+h},a_{t+h})\right],
\quad C(\widehat G,a)=\mathrm{true}.
\]

其中，观测为 \(o_t\)，领域知识为 \(K\)，\(U\) 更新图状态，\(F_\theta\) 描述行动条件变化，\(R\) 评价任务收益，\(C\) 表示约束。图状态只是对当前信息的表示；在局部可观测环境中，单一确定图不天然等于完整的信念分布。

如果系统只具备 \(U\) 和检索问答，它可以维护有用的世界知识，但尚未独立验证 \(F_\theta\)。如果系统估计 \(p(s,r,o\mid G_{\leq t})\)，它可以预测事件，但没有显式动作或干预变量时，尚不能据此比较“改变行动会怎样”。如果系统用 PDDL 规定动作效果，则动态模型可以是符号定义的，不一定需要学习。

这一分解吸收了 [P01 世界模型综述](https://arxiv.org/abs/2411.14499v4)关于表示与预测的视角，以及 [P07 RAP](https://arxiv.org/abs/2305.14992)对世界模型与搜索的组织方式。公式与模块划分是本文的综合分析。

### 2.2 知识增强的五个位置

| 增强位置 | 典型技术 | 期望收益 | 应优先验证的量 |
|---|---|---|---|
| 状态表示 | 本体、语义图、情景记忆 | 减少事实碎片化和记忆遗失 | 状态正确性、过时事实比例 |
| 动态预测 | 图演化网络、时序规则、图增量生成 | 更准确地预测事件或状态变化 | 时间外推指标、多步误差 |
| 行动生成 | 能力图、可达图、前置条件 | 减少不可执行动作 | 动作有效率、计划可行率 |
| 方案评估 | 规则约束、价值模型、搜索 | 选出任务收益更高的方案 | 成功率、代价、搜索预算 |
| 解释与复核 | 图查询、证据路径、来源记录 | 支持检查依据和失效原因 | 证据覆盖、解释忠实性 |

上述收益是待验证假设。“使用知识图谱”不是能够替代这些指标的评价结果。

## 3. 方法演化：五条相互关联的路线

### 3.1 从潜在世界模型到显式图动态

[P02 World Models](https://arxiv.org/abs/1803.10122)和[P03 DreamerV3](https://www.nature.com/articles/s41586-025-08744-2)说明，可以通过学习环境动态、在想象轨迹上改进行为。这类方法提供了闭环思路，但其表示通常不是可直接查询的领域知识图谱。对本课题而言，它们更适合作为“预测必须服务于行动”的参照，而非直接复用的指挥系统。

[P04 Worldformer](https://arxiv.org/html/2106.09608v2)更直接地连接图与行动：输入包括当前观测、状态图、有效动作和执行动作，输出下一状态的图变化及有效动作集合。它说明图世界模型可以被定义为明确的监督学习任务，而不必先生成整段视频。不过，这项工作的核心证据是文本环境中的预测任务，不是完整任务规划收益；由环境提供的状态或有效动作信息在真实系统中也未必可得。

**综合判断**：图表示的优势在于实体、关系和约束容易检查；其代价是图抽取和更新本身会犯错。研究时应同时记录预测误差与表示误差，不能把已构造的图默认成真实状态。

### 3.2 从历史图到未来事件：态势预测的可落地切口

[P11 RE-GCN](https://arxiv.org/html/2104.10353)用关系图卷积与循环演化表示建模历史图序列；[P12 TLogic](https://arxiv.org/html/2112.08025)从时间一致的路径中学习规则并预测未来链接；[P13 TiRGN](https://www.ijcai.org/proceedings/2022/299)补充局部与全局历史模式。这条路线的优点是输入输出较明确，容易先建立基线。

需要区分两种预测：给定未来查询中的主体、关系和时间，排序可能对象；以及从当前状态主动生成未来的全部重要事件。前者即使指标较好，也不自动具备后者的覆盖能力，更没有直接决定行动方案。

对于神经演化与规则推理，本文不作普遍优劣判断。前者适合学习难以显式列举的模式，后者便于检查命中路径。真正有价值的比较应固定数据、历史可见性、过滤规则和候选集合，同时检查高频重复事件是否已经解释了大部分收益。

### 3.3 从非结构化历史到图记忆：改善长任务执行

[P05 AriGraph](https://arxiv.org/html/2407.04363v3)将环境事实与情景记忆连接，并在交互中更新记忆。其方法对本课题的价值，是把“当前知道什么、这些知识来自哪些经历”组织为可检索结构。该工作用共同的规划和决策模块比较不同记忆方式，因此较适合设计记忆机制对照。

其 TextWorld 结果采用五次尝试中表现最好的三次平均。若后续做独立实验，应同时保留论文口径和全部预定尝试的统计，避免把选择性汇总误认为任意一次运行的典型表现。

[P08 DAVIS](https://arxiv.org/html/2410.09252v2)进一步把转移经历写入时序图，通过多轮查询近似未来变化和奖励，再结合执行中的批评与重规划。它比单次图检索更靠近模型辅助规划，但近似质量仍依赖 LLM、历史覆盖和调用预算；方法中存在转移模型符号，不等于已经证明其预测经过概率校准。

**综合判断**：图记忆是任务规划的有力支撑，但记忆方法优劣和动态预测方法优劣需要分别实验。只有任务成功率提高，尚不足以确定收益来自预测、检索还是更多模型调用。

### 3.4 从知识到可执行计划：参数约束与符号约束

[P06 WKM](https://arxiv.org/html/2405.14205v4)把任务知识与状态知识区分开来，使用训练和检索约束代理行动。它不是显式知识图谱方法，其对照意义在于提醒：知识可以通过参数、检索分布或提示进入决策。论文的特定实验中，直接把状态知识加入上下文的效果弱于其检索约束方案，不能由此推导“所有显式图都无效”，但足以反对“知识越多、提示越长越好”的假设。

[P09 KGLAMP](https://arxiv.org/html/2602.04129v2)用关系、属性与可达性图指导 PDDL 生成，并在失败时更新知识和重规划。这条路线把“语言上合理”进一步转化为“在已建模条件下可执行”。其边界是符号域和动作效果是否正确：计划在模型里有效，不保证在噪声观测或遗漏前置条件的环境中有效。

[P07 RAP](https://arxiv.org/abs/2305.14992)及其[LLM Reasoners 工程](https://github.com/maitrix-org/llm-reasoners)则提供状态转移、奖励与搜索的模块化组织方式。它适合作为后续规划对照框架；搜索预算和世界模型误差必须共同控制，不能仅用增加搜索次数证明推理更可靠。

### 3.5 面向领域决策支持：知识可靠性优先于回答流畅度

[P15 E-KELL](https://arxiv.org/html/2311.08732)把应急领域知识结构化，并借助提示链提供决策支持；[P16 ARES-KG](https://www.mdpi.com/2673-9585/6/3/16)以图查询和显式依赖支持可追溯分析。它们与应用目标直接相关，但知识支持回答的评价，与预测和执行闭环的评价并不等价。

ARES-KG 的论文还披露了知识覆盖、冲突处理及更新方式的限制。因此，不能把某条查询有确定结果，扩展为整段 LLM 回答都经过图验证，更不能把图中的因果命名扩展为经过干预识别的因果效果。

中文[P17 态势估计](https://jcdz.cbpt.cnki.net/portal/journal/portal/client/paper/1c4b40ac6cea80db58edd9c07927c151)、[P18 行动判识](https://opaj.napstic.cn/periodicalArticle/0120240703074246)及[P19 意图识别](https://www.techscience.com/cmc/v80n1/57424/html)补充领域术语和子任务定义。本轮尚不足以评价前两项的全文实验；不把摘要中的“支持预测或决策”直接标记为完成预测或规划验证。

## 4. 横向比较：研究对象比模型名称更重要

| 代表工作 | 图或知识扮演的主要角色 | 原生输出 | 对本课题有支持的环节 | 仍需另证的环节 |
|---|---|---|---|---|
| Worldformer | 显式状态与变化对象 | 图增量、有效动作集合 | 行动条件预测 | 长任务决策收益 |
| RE-GCN / TiRGN | 历史动态图 | 未来实体或关系排名 | 事件外推 | 干预效果、方案执行 |
| TLogic | 规则学习对象与证据路径 | 候选排名、规则依据 | 可解释事件预测 | 真正因果效应 |
| AriGraph | 语义与情景记忆 | 记忆检索、代理行为 | 状态保持、长期任务 | 独立动态模型的精度 |
| DAVIS | 时序经历与多轮检索 | 近似轨迹、行动与反馈 | 检索辅助规划 | 校准、多模态及成本稳定性 |
| WKM | 参数化先验与状态检索库 | 行动分布和任务执行 | 知识约束 | 显式图带来的额外收益 |
| KGLAMP | 能力、关系与可达性约束 | 符号问题、计划和修正 | 可执行性、重规划 | 未建模动态与真实观测误差 |
| E-KELL / ARES-KG | 领域证据与依赖结构 | 辅助回答、图查询分析 | 解释、资料整合 | 闭环任务成效 |
| Graphiti / GraphRAG | 动态记忆或文档检索 | 事实与上下文 | 数据基础设施 | 未来预测和规划 |

最后一行参见[P20 Graphiti](https://github.com/getzep/graphiti)与[GraphRAG 官方工程](https://github.com/microsoft/graphrag)。[P21 KnowVal](https://openaccess.thecvf.com/content/CVPR2026/html/Xia_KnowVal_A_Knowledge-Augmented_and_Value-Guided_Autonomous_Driving_System_CVPR_2026_paper.html)属于自动驾驶迁移参考，启发知识检索与价值评估的分工，不把驾驶成绩当成指挥场景证据。

表中“仍需另证”是面向本课题的限制，不等于原论文本来承诺解决这些问题。

## 5. 如何评价现有证据

### 5.1 四类证据不能互换

本文区分：①出版和方法描述；②离线预测或问答实验；③仿真交互任务结果；④真实场景闭环验证。这不是简单质量排名，而是结论适用范围。一个设计严谨的离线实验可以有力支持预测方法，却仍不能证明实际决策收益。

本仓库当前样本中，领域工作与通用交互工作之间存在任务和数据鸿沟。本文未找到可以直接当作“知识图谱增强态势预测与指挥规划”统一基准使用的现成组合；这只描述当前检索样本，不能据此宣称整个领域不存在相关基准。

### 5.2 预测协议与历史信息

[P14 TGB 2.0](https://arxiv.org/html/2406.09639)强调数据版本、单步/多步设置和负采样差异可影响比较。对本课题，至少应分开三种设置：

- **在线一步预测**：预测后获得新的真实观测，再预测下一步。
- **固定起点预测**：起点之后不获得真值，历史可以保持不变。
- **自主滚动预测**：把模型预测回写到历史，持续产生多步状态。

RE-GCN 的静态代码审查揭示一个值得后续核对的细节：README 的示例多步命令设置 `--topk 0`；对应代码在 top-K 为零时不生成回写事实，历史列表保持不变。因而该示例不应直接称为“完整自主图演化”。这是对固定提交的静态推导，不是运行发现。详见[审查 E07](07_第二轮证据审查.md)。

同样，排序评估可能给定未来查询的主体和关系。模型处理这些查询，与系统自主预测哪些事件将出现仍有距离。

### 5.3 指标和预算

事件排序应明确 MRR、Hits@K 的过滤及并列规则；状态预测可评价图增量的精确率/召回率、互斥冲突和多步一致性；规划应评价目标完成、动作可执行性、资源消耗和时间；解释应检查结论是否可由实际使用的证据支持。某一条路径“读起来合理”，不等于解释忠实于系统的决策过程。

API 代理还应报告输入/输出 token、重试、模型版本和调用次数。比较相同模型但允许图方法调用更多轮，无法单独确定结构化表示的贡献。公平实验应同时给出功能相同的对照和预算可比的对照。

## 6. 本课题可以切入的三个研究问题

以下为本文提出的研究假设，不是已经完成的新颖性判断或实验结果。

### 6.1 时间与置信度是否比扩大图规模更有用？

假设：对动态态势，处理事实失效、来源冲突和预测不确定性，可能比持续加入更多三元组更有价值。可对比静态图、仅时间戳图、带有效期与来源图，在一致事件流上分别测量状态误差、未来事件排序与下游任务收益。首先应确认数据是否真的含有这些标注；不能用人工编造的置信度宣称现实可靠性提升。

### 6.2 图记忆何时应触发重规划？

假设：只在关键前置条件失效时重规划，可能比每一步重新生成整段计划更省预算。可借鉴 AriGraph 的记忆组织、KGLAMP 的符号约束和 DAVIS 的执行反馈，但首次研究应只变更一个机制，避免把三个系统拼接后无法解释收益来源。

### 6.3 预测更远是否一定决策更好？

假设：长预测跨度可能因误差累积降低计划收益，存在适合任务的预测范围。可测量不同跨度下的预测误差、方案排序稳定性与目标完成率。[P10 图世界模型误差研究](https://arxiv.org/html/2606.27780v3)提供相关理论线索，但其界限依赖有界误差、平滑性及 rollout 内固定节点身份等假设，不能直接拿来保证任意现实态势图的稳定性。

## 7. 面向后续研究的路线建议

推荐把第一阶段分成两个互补但独立的验证问题：**TLogic/RE-GCN 检验历史图是否支持未来事件预测；AriGraph 检验图记忆是否改善长任务执行。**二者都取得可解释结果后，再选择是否研究行动条件图转移。

若目标更偏算法论文，应先明确一个任务、一套时间协议和一个可解释的增强位置。若目标更偏工程展示，可借鉴 ARES-KG 的知识查询组织，但必须如实说明展示的是资料分析与证据检索，还是经过仿真验证的方案比较。两个方向都可以有价值，不应互相替代。

完整路线至少需要一个评价用环境或真值来源。对同一初始状态比较不同动作的后果，不能只靠被评价的 LLM 自己判断；否则预测器、规划器和裁判可能共享同一种错误。

## 8. 结论与适用范围

本轮综述支持把该方向理解为“以结构化知识支撑预测和规划的混合系统”，而非某一个统一模型架构。知识图谱最清楚的价值在于组织关系、维护记忆、暴露约束与追溯证据；其对未来预测和任务收益的增益必须通过独立实验建立。

在现有材料基础上，建议优先考虑依赖较轻且评估链路明确的 TLogic，以及最贴近长任务记忆问题的 AriGraph；RE-GCN 是有意义的神经预测对照，但需先解决旧依赖和协议问题。其余工作分别保留为方法、系统或后续候选，详见[可行性报告](06_复现与测试可行性.md)。本轮所有判断均止于文献阅读和静态审查，尚没有运行成功、性能提升或复现失败的实测结论。
